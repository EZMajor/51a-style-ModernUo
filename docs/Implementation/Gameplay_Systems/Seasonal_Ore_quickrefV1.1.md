## 🎯 Skill Jewelry System

| Skill | Base Cap | Max w/ Jewelry | Full Set Required |
|-------|----------|----------------|-------------------|
| Mining | 100.0 | 120.0 | 4 pieces (+5 each) |
| Blacksmithing | 100.0 | 120.0 | 4 pieces (+5 each) |

### Two Set Types

| Set | Skills Affected |
|-----|-----------------|
| **Resource Gathering** | Mining, Lumberjacking, Fishing, etc. |
| **Crafting** | Blacksmithing, Tailoring, Carpentry, Tinkering, etc. |

### Set Pieces (+5 Each)

| Slot | Bonus |
|------|-------|
| Necklace | +5 |
| Earrings | +5 |
| Ring | +5 |
| Bracelet | +5 |
| **Full Set** | **+20** |

### Decay Rules

| Rule | Value |
|------|-------|
| Timer Starts | **First equip** (not on creation) |
| Duration | **7 days** from first equip |
| Crafting | GM Tinkering + Dungeon Relics |

## Key Rules Summary

| Rule | Details |
|------|---------|
| Rotation | Every 3 months (real-world seasons) |
| Iron | Always available |
| Max Skill | 120.0 with full jewelry set |
| Jewelry Set | 4 pieces (Neck, Ears, Ring, Bracelet) = +20 |
| Jewelry Decay | 7 days from **first equip** |
| Legacy Items | Keep forever, cannot mine until season returns |
| Runic Tools | Rotate with seasonal ore set |
| Armor | AR increases with tier |
| Weapons | Elemental bonuses PvM ONLY |
| Tier 6 | 90% smelt / 80% craft @ 120 skill |
| BODs | Current season materials only |
| Town Cryer | Broadcasts first 7 days of new season |
